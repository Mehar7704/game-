PAGAL ❤️ MUHTRMA — PERSONAL PHOTO PUZZLE

YOUR PHOTOS ARE INCLUDED
The images folder contains all 7 photos extracted from the pics.rar archive and prepared for the square puzzle board.

HOW TO START
1. Extract Pagal_Muhtrma_Puzzle.zip.
2. Open the Pagal_Muhtrma_Puzzle folder.
3. Double-click index.html to open the game in Chrome or Edge.
4. Choose one of the 7 photos, choose Classic or Heart puzzle, select difficulty, then click Shuffle & Start.

SAVE & RESUME
- Progress auto-saves in the same browser using localStorage.
- Use Continue Game to resume the last saved puzzle with the same photo, difficulty, puzzle type, placed pieces, moves, and elapsed time.
- Use Save Progress to manually save at any time.
- Browser data clearing, private/incognito mode, or switching browsers/devices can remove or hide saved progress.
- The saved state is stored on the device in the browser; photos are not uploaded to a server.

FEATURES
- Wooden, Romantic, and Galaxy themes
- 7 included photos
- Classic square puzzle and heart-shaped puzzle board
- 3x3, 4x4, 5x5, 6x6, and 8x8 difficulty
- Drag-and-drop on desktop; tap a piece then tap its destination on touch devices
- Move count, timer, hint, fullscreen, victory animation
- Save and continue later

CUSTOMIZE MESSAGE
Open index.html and search for “Puzzle complete, Muhtrma Ji!” or “Pagal Ki Jan Hain Aap” to edit the winning message.

TIP
For best results, open the project in Chrome or Edge. If the browser blocks local images when opening index.html directly, use VS Code Live Server.

AUTO NEXT LEVEL
- When a puzzle is completed, a celebration modal appears.
- The next photo level starts automatically after 4 seconds.
- You can also press the Next Level button to continue immediately.
- After all 7 photos, the game starts a new round and increases difficulty.
